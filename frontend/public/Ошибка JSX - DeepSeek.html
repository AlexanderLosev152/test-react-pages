Ошибка JSX
Ошибка JSX

Проблема в том, что вы пишете код с типами TypeScript (интерфейсы, типизация пропсов) внутри файла с расширением .jsx (App.jsx).

TypeScript-синтаксис (например, interface, : AppProps) работает только в файлах .ts или .tsx.

У вас есть два пути решения:

Вариант 1: Переименовать файл (Рекомендуемый)

Поскольку вы уже используете типизацию, логичнее использовать TypeScript для всего проекта React.

  1. Переименуйте файл App.jsx в App.tsx.

  2. Ошибка исчезнет, так как .tsx поддерживает и JSX, и TypeScript.

Вариант 2: Убрать типы (Если вы хотите писать на чистом JS)

Если вы не хотите использовать TypeScript в этом файле, вам нужно удалить весь типизирующий код:

  1. Удалите блок interface AppProps { ... }.

  2. Уберите тип в аргументах функции.

  3. Убедитесь, что переменная navItems приходит откуда-то (так как сейчас в коде она просто типизирована, но не импортирована).

Код должен выглядеть так (без типов):

javascript

import Header from './components/sections/Header/Header';
// import { navItems } from '@/data/navItems'; // Раскомментируйте, если данные берутся отсюда

function App({ navItems }) { // Убрали : AppProps
  return (
    <>
      <Header navItems={navItems} />
    </>
  );
}

export default App;

Совет: Судя по вашему скриншоту, у вас уже есть файлы .tsx в проекте (например, Header.tsx). Поэтому Вариант 1 (переименовать в App.tsx) — самый правильный.
